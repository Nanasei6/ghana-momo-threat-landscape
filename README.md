## Project Overview

This project is a Sector-Specific Threat Landscape Report assessing the human-centric cyber threats facing Ghana's mobile financial ecosystem. The report examines four interconnected pillars:

1. **Mobile Money (MoMo) Ecosystem** — The battlefield and its structural vulnerabilities
2. **Social Engineering** — The weapon: culturally tailored manipulation of human psychology
3. **Digital Lending** — The frontier: platforms as both fraud victims and data predators
4. **Regulatory Framework** — The fragmented shield: gaps in Act 1038, Act 843, and institutional coordination

## Methodology

This is an analytical research project employing systematic Open Source Intelligence (OSINT) collection and analysis. The methodology includes:

- Systematic literature review of 24 academic and industry sources (IEEE, SSRN, Google Scholar)
- MITRE ATT&CK framework mapping
- Regulatory analysis of Ghana's Cybersecurity Act 2020 (Act 1038), Data Protection Act 2012 (Act 843), and Bank of Ghana directives
- Threat classification using the Zaoui et al. (2024) social engineering taxonomy
- Professional threat intelligence report structuring (TLP:AMBER classification)

**Note:** This is a research and analysis project, not a practical lab-based project. The deliverable is the threat intelligence product itself — a comprehensive assessment grounded in vetted sources and structured for a CISO audience.
